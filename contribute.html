Open source

Teach one idea in 3D. Leave it where everyone can use it.

A growing library of interactive biology, built in the open. Plain HTML and Three.js, no build step, so a coding agent can add to it in an afternoon. What an agent cannot judge is whether the science is right, or whether a student would learn anything. That part is ours together.

How to contribute GitHub AGPL-3.0 · no build step · no account

Agents made this cheap

Building in 3D used to mean learning Three.js first. Now you say what you want to teach, and your agent drafts it from the docs already in this repo.

Review is the scarce part

Agents write good graphics and plausible biology. Plausible is the problem: a wrong bond angle renders beautifully. Someone who knows the subject reads every contribution.

One library compounds

Fifty people generating alone gives fifty half-finished cells nobody else can reach. Add to one library and the next person's lesson mounts your cell by name.

Start

Hand this to your agent

Claude Code, Cursor, Codex, whichever you use. It clones the repo, reads the docs and builds. Replace the one line that says what you want.

Clone https://github.com/rhymeandreason/ScienceSandbox and read
demos/CLAUDE.md, then the one doc its "What to read" table names for this
task. Follow that doc exactly, including the parts that look like they do
not apply.

TASK: <one sentence: what to add, and what it should teach>

Worth repeating from the repo:
  - Three.js r128 as a global script. No build, no bundler, no modules.
  - Never type an atom or bond colour. palette.js publishes them as tokens.
  - Molecule coordinates are real angstroms, not display units.
  - A claim about chemistry ships with the check that verifies it.
  - Write like a tutor for a first-year biology student.

Start the dev server with node demos/tools/dev-server.js, run the checkers,
then tell me exactly what to click to see whether it is right. Do not tell
me it works. I will look.

Ask for the click, not a verdict. Nothing in the repo can check framing, timing, or whether an animation reads as the thing it claims to show.

components exist already. Mounting one is a line of code; adding the next is AddingAComponent.md.

Review

Open a pull request, and expect a real read

Branch off main and open a PR. Say what a student should learn, what you checked, and what you are unsure about. That last one is the most useful sentence in it.

Expect edits on the copy and questions on the science. Slow is fine. Confidently wrong and beautifully rendered is the failure this project is organised against.

Open an issue first →

What gets checked

  1. Is the science right? Geometry, mechanism, and what a simplification quietly implies.
  2. Would a student learn it? One idea, carried. A scene that shows everything teaches nothing.
  3. Does it run? Safari and Chrome, on a laptop-sized window.
  4. Does it hold the invariants? No build step, r128, tokens for colour, ångströms for coordinates.
  5. Do the checkers pass? The pre-commit hook runs them, so this usually answers itself.
Run it yourself

If you would rather drive

Your agent does all of this. Here it is by hand.

  1. Fork, then clone your fork

    git clone https://github.com/YOUR-USERNAME/ScienceSandbox.git
cd ScienceSandbox

  2. Start the dev server

    Node only. No install, no build. Open http://localhost:8817/. Saving a file reloads just the pages that use it, and a CSS change swaps in place, so a scene keeps its camera while you tune it.

    node demos/tools/dev-server.js

  3. Optional: the checkers

    Only needed for molecules. Points git at .githooks so the offline checkers run before each commit, and installs RDKit for the handedness check. The pages still need nothing.

    cd demos && npm i
node check-molecules.js        # geometry, bond angles, stereo claims
node tools/check-pages.js      # every page still loads what it needs

The code

AGPL-3.0. Anything built on this stays open, including a hosted copy. A classroom should be able to take a lesson apart, and the next classroom should get that back.

The words and pictures

CC BY-NC 4.0. Lesson copy, images and rendered stills. Teach with them and remix them for your class, with credit. Selling them is a conversation, so ask. Where the line falls inside one file is in LICENSING.md.

Credit

Structures come from the Protein Data Bank, credited to the labs that deposited them. No CLA and no copyright assignment: opening a PR licenses it under both, and you keep your copyright.
