step 1 · transcription

Transcribe DNA → mRNA

RNA polymerase reads the DNA template strand and builds a matching mRNA. Pair each base: A→U, T→A, G→C, C→G. (RNA uses U instead of T!)

DNA template strand (3'→5')
mRNA you're building (5'→3')
step 2 · translation

Translate mRNA → protein

Ribosomes read mRNA in codons (groups of 3). Each codon calls in a tRNA carrying one amino acid. Chain them up to build the protein!
