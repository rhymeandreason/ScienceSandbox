massaction.js — test bench

Three mounts of the same module, side by side, with no lesson around them. Each panel builds its own DOM from a scenario list; nothing on this page styles the sim.

A — glycolysis, as shipped. Two scenarios, fixed barrier. Should be indistinguishable from the modal in glycolysis-lab.html; if it is not, the extraction dropped something.

B — the enzymes page's interaction. A barrier you can drag. Watch both rates climb together and the settled split stay where it was — a catalyst speeds a reaction, it cannot shift an equilibrium. The hump in the curve must shrink with the slider.

C — one scenario, no tabs. The branch glycolysis never takes. ΔE is a round 3 kT: about 1 reverse in 20, so the reverse counter should tick slowly but never sit at zero.
