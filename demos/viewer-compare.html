3Dmol.js vs ChemDoodle Web — same file, same style, side by side

3Dmol.js

ChemDoodle Web

What to look at:
  • Load time in each header — same bytes, parsed twice.
  • Cartoon quality. 3Dmol draws proper secondary-structure cartoons (arrows on strands, tubes on loops); ChemDoodle draws a ribbon. Compare on 1IGT, which is nearly all β-sheet.
  • Molecular surface. 3Dmol computes one (SES/SAS); ChemDoodle Web has no surface — pick "Molecular surface" and read the right-hand note.
  • Big structures. 1AON is the honest test of whether either can carry a lesson on a school Chromebook.
  • Ligands. 3CYT's heme and 1ATN's ATP — do they survive the cartoon representation, and are they coloured usefully?
  • Licence. 3Dmol.js is BSD-3. ChemDoodle Web is GPLv3 (or paid commercial) — GPL would mean this whole repo, published on GitHub Pages, inherits GPL terms. Worth settling before we invest.
