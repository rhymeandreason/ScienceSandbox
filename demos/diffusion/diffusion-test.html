diffusion.js — test bench

Three mounts of the same module. Nothing on this page styles the sim, and nothing sets a rate: every speed below is read from a molecule's own coordinates through radiusOf and Stokes–Einstein.

A — nothing knows the gradient. All the water starts on the left. No line of code reads the concentration; the crowd thins because there are more dots on the left to wander off it. Watch the net arrow go flat while both crossing counters keep running — evened out, not stopped.

B — size sets the rate. Water and glucose, same start, same code, two radii. Glucose is about 3× slower — a prediction from its own atom coordinates, not a number typed here. This is the argument the membrane page needs.

C — √t, with the trails on. Six molecules from one point. Each path is a stagger going nowhere in particular; the crowd still spreads at a rate you can plot. The measured line leaves the dashed one when the crowd reaches the walls — the box ended it, not the physics.
